# Скорая помощь при панической атаке — InTreatment

Интерактивный инструмент самопомощи: дыхательный тренажер, игра «Блоки», пять аудиоинструкций Екатерины Логиновой с текстами, шкала тревоги, видеообращение и запись к психологу через Telegram-бот.

Это статическая страница: один HTML-файл и папка с медиа. Сборка, сервер приложений и база данных не нужны.

## Состав

```
intreatment-panika/
├── index.html        — вся страница: разметка, стили и скрипты внутри
├── README.md         — этот файл
└── media/
    ├── a1_panic.mp3  — «Как устроена паническая атака», 9:13
    ├── a2_switch.mp3 — «Переключаем режим», 4:49
    ├── a3_relax.mp3  — «Включаем режим расслабления», 5:23
    ├── a4_pmr.mp3    — «Нервно-мышечная релаксация», 7:15
    ├── a5_why.mp3    — «Почему возникает паническая атака», 5:09
    ├── intro.mp4     — видеообращение (кружок), 0:55, H.264 + AAC
    └── intro.jpg     — обложка видео и картинка для превью ссылки
```

Общий вес около 21 МБ, из них страница — 150 КБ. Аудио: MP3, моно, 80 кбит/с.

## Как разместить

1. Скопировать папку целиком на любой статический хостинг или в nginx, например по адресу `https://intreatment.online/panika/`.
2. Обязательно HTTPS: без него на телефонах не работают кнопка «Поделиться», копирование ссылки и удержание экрана включенным во время дыхания.
3. Сервер должен отдавать аудио и видео с поддержкой `Range` (ответ `206 Partial Content`). Без этого в Safari не работает перемотка аудио, а видео может не запуститься. nginx и большинство хостингов делают это по умолчанию.
4. Типы файлов: `.mp3` → `audio/mpeg`, `.mp4` → `video/mp4`, `.jpg` → `image/jpeg`.
5. Кэширование: для `media/` можно ставить долгий кэш (`Cache-Control: public, max-age=31536000, immutable`). Для `index.html` — короткий или `no-cache`, чтобы правки сразу доходили до людей.

Пример для nginx:

```nginx
location /panika/ {
    alias /var/www/intreatment-panika/;
    index index.html;
}
location /panika/media/ {
    alias /var/www/intreatment-panika/media/;
    add_header Cache-Control "public, max-age=31536000, immutable";
}
```

## Что проверить после публикации

- **Превью ссылки.** В `<head>` для `og:image` указан относительный путь `media/intro.jpg`. Telegram и WhatsApp надежнее показывают картинку с абсолютным адресом: заменить на полный, например `https://intreatment.online/panika/media/intro.jpg`, и добавить `<meta property="og:url" content="...">` с адресом страницы.
- **Ссылка «Поделиться».** Берется автоматически из адреса страницы (`location.origin + location.pathname`), настраивать ничего не нужно.
- **Запись к психологу.** Все кнопки записи ведут на `https://t.me/Intreatmentpsy_bot`, «Подробнее о проекте» — на `https://intreatment.online`. Если адреса поменяются, искать по этим строкам в `index.html`.
- **Шрифты.** Playfair Display и Golos Text подключаются с Google Fonts. Основной текст набран Helvetica Neue, Golos Text нужен как запасной. Если Google Fonts нежелательны, можно скачать шрифты к себе и заменить `<link>` в `<head>` на `@font-face`.

## Как устроено

- **Без зависимостей.** Чистые HTML, CSS и JavaScript, внешних библиотек нет.
- **Режим «Мне плохо».** Полноэкранное окно с тремя шагами: дыхание, игра, голос Екатерины. Пока окно открыто, приложение просит браузер не гасить экран (Wake Lock), если браузер это поддерживает.
- **На телефоне** (ширина до 999 px) страница прокручивается внутри контейнера `#scroller`, а нижняя панель инструментов и мини-плеер стоят неподвижно. Это сделано специально: на iPhone фиксированные панели иначе «плавают» при прокрутке. На компьютере прокрутка обычная.
- **Темная тема** включается по системной настройке. При включенной настройке «Уменьшить движение» анимации отключаются.
- **Без JavaScript** сверху показывается плашка, а неработающие блоки скрываются (`<noscript>`).

## Данные и приватность

Страница ничего не отправляет на сервер. В `localStorage` браузера человека хранятся только его собственные отметки:

| Ключ | Что хранит |
|---|---|
| `pa-scale` | замеры тревоги 1–10 с временем; новая серия начинается, если прошло больше 8 часов |
| `pa-listened` | какие записи прослушаны |
| `pa-rate` | выбранная скорость аудио |
| `pa-autonext` | включено ли «Слушать подряд» |
| `pa-steps` | пройденные шаги «Дыхание / Игра / Голос» |

Отметки в блоках «Что вы чувствуете?» и «Из каких проводов собрано напряжение» нигде не сохраняются.

Если будете добавлять аналитику, не передавайте в нее ответы людей: оценки тревоги и отмеченные ощущения — чувствительные данные.
